# 映作 · A 测版前端

这是本地绘图工作台的视觉与交互预览。“映作”为暂定名称。

当前是浏览器中的 WebUI 原型；最终目标是独立 Windows 桌面应用，包含统一窗口、服务启停和托盘，不以网页预览作为最终产品交付。

项目进度与接下来的开发安排见 [项目总结与后续排期](../项目总结与后续排期.md)。

双击 `Start-Preview.cmd` 即可打开。也可以直接打开 `index.html`，无需安装前端依赖。

预览地址：<http://127.0.0.1:8840/>。使用 Python 标准库提供静态页面，仅监听本机，不提供绘图或文件管理 API。重复启动会复用本预览服务；端口被其他程序占用时改为直接打开 HTML 文件。

## 可以体验

- 首页、创作、工作流库、资源管理、作品库、收藏板、设置与维护。
- 五个已有工作流的表单布局，切换工作流分别保留提示词草稿。
- 简洁表单与节点结构示意切换，共享提示词；图形画布还不是 ComfyUI。
- 侧栏保留“创作 / 节点画布”入口，首页可直接选择简洁表单或节点模式；节点画布可通过 `#canvas` 访问。
- 创作页使用顶部“工作流 / 视图”菜单和多个工作流标签页。点击“＋”进入独立的新建起始页：导入 JSON、选择已有模板、新建空白节点画布。选择模板会在当前新标签中创建独立副本；从工作流库普通打开仍复用已有标签。
- 每个标签分别保存提示词、参数、参考图片、表单／节点模式及缩放；支持标签重命名、关闭、恢复最近关闭标签、刷新恢复。上传图片的内存引用仅本次会话有效。
- 画布页另有本机 ComfyUI 入口（需要先启动原 ComfyUI 服务）；该入口不自动载入 A 测工作流，也不代表已完成内嵌编辑与双向同步。
- 节点画布顶部提供“运行”按钮，图像模板进入演示队列并显示进度，提示词模板打开润色预览；导入工作流待 ComfyUI 接入，空画布无节点时禁用运行。
- JSON 支持拖入文件、文件选择和粘贴文本，先检查格式再导入，支持普通 ComfyUI 工作流和 API 格式。最大 2 MB，原始 JSON（含子图）保留在标签草稿中；支持定位到子图，每次最多展示 120 个节点。
- 空白节点画布是真正的 0 节点起点；添加节点、连线、真实运行及自定义表单映射等待后续接入。
- 提示词润色预览、参考图选取、尺寸和步数、串行演示队列、批量与取消。
- 模板与资源筛选、全局搜索（Ctrl + K）、大图预览、收藏、导出选项。
- 设置中切换青柠／雾紫强调色与图片展示密度。

## 预览边界

页面不会启动／停止 ComfyUI 或 LM Studio，不调用模型，不实际安装、更新、删除或导出图片。JSON 工作副本可以下载为新文件，原文件不会被改写。队列完成后仍展示已有图片；润色结果是规则拼接的示意文本。

模型清单来自规划时记录的环境资料，未实时扫描磁盘。图片是已有作品与参考图的副本，原文件未改动；作品详情中的画面摘要是演示文案，没有冒充原始提示词元数据。

草稿、导入的工作流 JSON、内置图片收藏、模板收藏与外观选择只保存在当前浏览器的本地存储。存储不可用或满时会提示，最新修改仅本次会话保留；尚未确认导入的粘贴文本也仅保留在本次会话。新上传的图片使用内存中的对象 URL，仅本次会话有效，不上传到任何服务。

先评审配色、布局、图片展示、信息密度与操作路径；视觉方向确认后才进入实际功能接入。

## 文件

- `index.html`：页面容器。
- `style.css`：视觉样式与响应式布局。
- `icons.js`：本地 SVG 图标。
- `app.js`：页面、状态与演示交互。
- `workspace-tabs.js`、`workspace-tabs.css`：多标签工作区、菜单、独立草稿与会话恢复。
- `canvas-mode.css`：节点画布入口与布局。
- `workflow-start.js`、`workflow-start.css`：三种新建入口和自定义工作流预览。
- `workflow-import.js`：JSON 格式校验；`tests/workflow-import.test.cjs`：解析边界测试。
- `assets/`：标识、已有作品和参考图的本地副本。
- `preview.py`：可选的本机静态预览服务。

## 导入模型检查与快速修复

导入 JSON 后自动显示“导入检查”，可搜索节点、模型，查看参数路径并定位到主画布或子图。检查常用加载节点、模型引用、用途和格式；明确区分待修正与待核实。子图提升到外层的模型参数按明确的输入映射检查，修复只改实例的实际生效值。

本机候选来自 `compatibility-catalog.js`，是模型文件、节点源码定义和已有 LM Studio 配置的只读快照；页面显示检查时间。它不是实时扫描结果，也不验证显存、服务是否加载成功或最终画质。未知插件、动态连线和不确定的参数映射保持待核实；没有可信替代时不强行推荐。

可靠字段映射可使用“预览替换 → 应用到当前副本”，随后自动重新检查。支持撤销上次修复、刷新后保留修复；导出窗口提供完整 JSON 预览、复制与下载，内嵌浏览器不支持下载时可以复制保存。不会自动改加载节点、断开连线、安装插件或下载模型；跨架构、跨服务和格式迁移提供手动处理说明。

目前快速替换规则覆盖已登记的 Qwen Image 2.1 量化版本、Qwen3 VL 8B 编码器精度、同名资源目录修正，以及已配置 LM Studio 润色节点的模型标识。LLaMA 与 Gemma 可以是相同润色用途的候选，但不表示输出或看图能力等价；语言 GGUF 不能当作图像 GGUF 直接替换。

- `compatibility.js`：静态检查、候选匹配、精确修改与撤销。
- `compatibility-ui.js`、`compatibility.css`：问题清单、定位、替换预览和 JSON 下载。
- `tools/snapshot_compatibility.py`：维护时生成本机快照，只读取文件和 Python AST，不导入插件或启动服务。当前脚本针对本机部署路径。
- `tests/compatibility.test.cjs`：用途隔离、加载器、子图、API 格式、补丁安全等测试。
