## 构建命令

```powershell
npm ci
npm run check          # 语法、接口白名单、界面检查、全部单元/集成测试
npm run build:win      # 仅 Windows：便携 exe + NSIS，生成 dist/artifacts.json 与 dist/SHA256SUMS.txt
.\dist\win-unpacked\映作.exe --yz-smoke=smoke.json   # 打包自检（不触碰用户数据）
```

GitHub Actions “Windows build”（`.github/workflows/windows-build.yml`）在 windows-latest 上执行以上步骤并上传产物 `yingzuo-windows`（exe、artifacts.json、SHA256SUMS.txt、smoke-result.json）。
