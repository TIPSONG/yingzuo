## 构建命令

```powershell
npm ci
npm run check          # 语法、接口白名单、界面检查、全部单元/集成测试
npm run build:win      # 仅 Windows：便携 exe + NSIS，生成 dist/artifacts.json 与 dist/SHA256SUMS.txt
.\dist\win-unpacked\映作.exe --yz-smoke=smoke.json   # 打包自检（不触碰用户数据）
```

GitHub Actions “Windows build”（`.github/workflows/windows-build.yml`）在 windows-latest 上构建并上传 `yingzuo-windows`。`aab1998` 对应构建包含 exe、artifacts.json、SHA256SUMS.txt、smoke-result.json、init-result.json；发布资产与清单的契约修正另由 [Issue #16](https://github.com/TIPSONG/yingzuo/issues/16) 跟踪。
