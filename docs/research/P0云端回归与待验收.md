## 真实 Windows / ComfyUI 验收清单

开始前检查 PR 分支、现有工作区改动、ComfyUI 服务状态，并复核既有部署保护基线。复用原运行环境，不升级插件、不清理历史草稿、不覆盖模板、不调用生成队列。以下每一项都应记录实际版本、时间、观察结果及落盘回读证据；无法执行写“未测”，而不是“通过”。

1. **五模板与身份**：依次打开文生图、多图编辑和三个 Gemma 模板。修改提示词与一个节点参数，往返切换并快速重复点击。宿主和原生标签均不得无故增加；返回后确认值仍在。只编辑，不运行模型。
2. **原生 JSON 导入**：通过文件选择器选中 `tests/fixtures/p0-app-mode.json`，确认成功路径、取消路径、无效 JSON 与超限文件处理。导入后原模板不变。
3. **官方 App Mode**：以上 fixture 切到 App Mode，确认配置输入及输出实际可见；编辑文本后回到节点与宿主参数表单，确认同一工作副本。未配置模板应明确拒绝切入，不得冒充配置成功。
4. **图片上传**：用明确的非敏感小图片（包含一次中文文件名）通过真实 LoadImage 控件上传，确认预览、后端 input 文件和图内引用一致。取消选择不应换掉旧图片。切换、重启后引用仍能读取。
5. **网页下载**：使用 ComfyUI 自身下载入口，确认 `.local/exports/` 实际文件内容和扩展名；连续同名下载不能覆盖。宿主原生 JSON 导出应另行验证，不能替代这一项。
6. **子图直接编辑**：进入已有多图编辑模板的子图，改动内部节点控件，回到根图、切换模板、保存、重启。回读完整 JSON，确认外层节点、子图定义、内部链接及修改值都保留。拖动后 Ctrl+Z 检查原生撤销。尤其不要把“能枚举子图参数”当作内部编辑成功。
7. **失败恢复**：在保护原草稿的前提下测试加载失败、保存失败、断线再连、原生标签内部切换和渲染器退出。失败后不显示错误图、不把旧参数写入另一图；关闭失败不丢标签或覆盖原草稿。破坏性场景用隔离副本进行。
8. **正常恢复与保护复核**：正常关闭／重开两次；确认已保存值、宿主活动标签及原生文档复用，再次复核既有部署保护文件。

P0 验收全部通过后才更新阶段状态。生成、Gemma 推理、服务自动启停、托盘与安装包仍是后续阶段范围，不为补齐 P0 擅自扩展。

## 本轮修复与最终云端结果

- 宿主标签创建／切换／关闭采用失败回退；先保存离开的副本，加载或最终持久化失败时保留原标签与活动选择，隐藏身份不确定的画布。
- 自动保存失败后，即使图没有继续变化也会重试；连续关闭窗口不会绕过正在进行的保存。
- 渲染器退出、导航与超时使过期结果失效；A 测预览进程失败不会误断开真实编辑器。
- 原生内部切换时先保全外来图。恢复文件写入失败会阻止重新加载和退出；重试保留首次快照以及仍在画布内发生的新修改。
- 参数编辑与导航共用忙碌状态；拒绝迟到结果，失败时显示权威快照，断连清除旧字段绑定。
- 桥接保存不可变文档 ID，阻止部分加载画布被当作原图保存；防止两个宿主标签绑定同一个原生文档，并在扩展回调之间重新核对控件与自动队列状态。
- 工作区写入前复用读取校验；拒绝稀疏节点／无效标签，处理 Windows 保留文件名。同名网页下载使用唯一目标，写入失败明确报告。

最终云端执行：`npm test` **101 项，100 通过、1 跳过、0 失败**；其中桥接 37 项、模拟主进程 22 项、模拟工作台 8 项、工作区 14 项。另有 Python 基线工具测试 **7 项通过**。所有桌面与测试 JavaScript 语法检查、差异空白检查通过。

唯一跳过项仍是 `COMFYUI_WORKFLOWS_DIR` 所指向的真实模板目录检查。上述云端检查完成时 GitHub Actions 尚未运行；最新运行状态以对应提交的 Actions 记录为准。这份记录不把云端测试、源码复核或 Electron 版本输出写成 Windows GUI／真实 ComfyUI 验收通过。

### 复审补充：原生加载全生命周期

复审确认前端 1.53.6 的 `loadGraphData` 先清空根图，再等待校验和扩展钩子，随后才设置 `ChangeTracker.isLoadingGraph`。单独检查该标志不足以保护早期空图窗口。

桥接现在为本会话的 `loadGraphData` 与 `loadApiJson` 安装全调用期保护，原样转发调用对象与参数，不修改已安装前端文件。原生加载开始即暂停读取／回写，失败或重叠加载不能重新授权部分画布；同一文档的原生撤销／重做完整成功后才恢复绑定。参数回调若启动新的加载，最后一项修改也不会返回部分图快照。新增 7 个模拟回归覆盖以上分支；真实 Windows 撤销／重做仍须操作验收。
